# Firmware Update Protocol

The update protocol is not finalized yet.

The final specification should define:

- Transport interface.
- Synchronization/start sequence.
- Firmware metadata.
- Maximum frame size.
- Sequence numbering.
- Acknowledgement and retry behavior.
- Timeout values.
- CRC/hash verification.
- Commit/activation command.
- Abort and recovery behavior.
- Firmware version policy.
- Power-loss behavior.

This document is intentionally a placeholder so that protocol decisions are recorded before implementation.
